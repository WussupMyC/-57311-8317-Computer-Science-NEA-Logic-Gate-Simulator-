About Simboard

   
            Simboard is a Logic Gate simulator built by Christopher Cupid for the A-Level Computer Science NEA project!

            Simboard offers a simple range of gates and objects for interaction to aim to produce an environment where people who 
            are just learning about Logic Gates can educate themselves further and take on the challenge of creating a simple circuit. 

            To create this simple web application, HTML (Hyper Text Markup Language) was used to construct the layout of the webpage, 
            and CSS (Cascading Style Sheets) was used to style said structure. Finally, JS (JavaScript) was used as the backend 
            handler of events and logic utilised within Simboard, from the element of interactivity, all the way up to the logic that
            each of the gates use.


How to use Simboard and Logic Gate objects

   
            To first utilise and learn about Simboard and Logic Gates, you must first understand what parts of the application do what.
            Below is an exemplar with each major area of Simboard highlighted and labelled:

        
            Appendix 1  -   The File Menu
                This UI Menu has the purpose of providing the user with innate controls over the interfact and project. 



            Appendix 2  -   The Object Menu
                This UI Menu has the purpose of providing the user with the objects that can be imported into the Workspace. 



            Appendix 3  -   The Workspace
                This UI Menu has the purpose of providing the user with the ability of interacting and connecting objects together
                to formulate a circuit. 



            Appendix 4  -   The "Simulate" Button

                

                This button acts as a toggle. If the button is toggled ON, the circuit can start working. Yet if the button is toggled
                off, the circuit stops working. This acts as a play/pause button for your Logic Gates!

                In order to see your circuit function, you must 'PLAY' your Workspace simulation.



            Appendix 5  -   The "Save" Button

                

                This button allows you to save either the Logic Gate circuit that you have made, or the UI Customisations you have 
                altered on your project. 

                Type the letter 'P' into the prompt when the save button is clicked to save the 'P'roject!
                Type the letter 'L' into the prompt when the save button is clicked to save the UI 'L'ayout!

                You will then be asked what you would like to name the file. Don't input a file extension - Simboard handles this!

                Finally, you will be able to enter your name or alias, although this is optional! 



            Appendix 6  -   The "Load" Button

                

                This function is tricky to utilise, but if done correctly, can allow you to access circuits or layout data!

                Once a file has been saved via the "Save" function, a .JSON file will be downloaded to your local disk drive. 

                If you would like to access this file again, and paste it into the session you are currently operating, you 
                must open your File Manager on your Device, and virtually drag and drop the downloaded .JSON file into the 
                Workspace.

                If the file was recognised, you should see a little animation play on Load Button icon that looks something
                like this:

                

                If you do see the animation similar to the image above, click the Load Button and follow the prompts 
                instructions.



            Appendix 7  -   The "Customise" Button

                

                This button allows you, the end user, to edit and modify the visual colour scheme of Simboard. 

                By clicking this button, you will be repeatedly prompted about each section of the Simboard application, 
                and you must make one of three choices:
                
                    Either...   enter a HEXADECIMAL VALUE, one that is 7 characters long and begins with a '#', e.g:
                    #FF3300...

                    ...Revert the UI element to its default value by entering the letter 'D' into the prompt...

                    ...Skip the specific UI customisation, or skip the rest of the prompts and apply all decisions by
                    entering 'X' into the prompt or by clicking 'Cancel'.

                All of this customisation data can be saved by saving 'Layout' in the Save function.



            Appendix 8  -   The "Engine Power" Button

                

                By clicking this button, you will be able to modify the depth of the Boolean Math calculated
                when the circuit is simulating. 

                Essentially, if you lower the value of the Engine Power, the Boolean Math will be less
                complicated, and is better suited for smaller circuits. 

                Yet, if you increase the value of the Engine Power, the Boolean Math will be more 
                complicated, and is therefore better suited for larger circuits. 

                If you increase the value too high, then Simboard may slow down in performance!

                If your Boolean Math value is too low, your circuits output may be either inaccurate or 
                faulty!



            Appendix 9  -   The "Line Solver" Button

                This button allows you to change or fix the positions of the visual lines that connect the 
                Logic Gate objects together.

                There are various modes that each do different things, and you can choose any from the 
                connections below:

                

                Line Solver Mode 0 makes all lines look like straight paths, from A to B. 

                

                Line Solver Mode 1 makes all lines look like squared, orthogonol paths.

                

                Line Solver Mode 2 makes all lines look curvy and bendy.

                

                Line Solver Mode 3 makes all lines appear transparent, depending on the value you enter.

                

                Line Solver Mode 4 makes all lines re-adjust to their required positions. 
                This is very useful after imports, where connections can get a bit messy!

                

                Line Solver Mode 5 makes all lines change colour, depending on the value you enter. 

                

                Line Solver Mode 6 makes all likes change thickness, depending on the value you enter.



            Appendix 10 -   The "Talk To System" Button

                

                This button, when clicked, acts as the "Command Prompt" for Simboard. 

                If you use this function, you will have a plethora of functions available to you, 
                including, but not limited to:

                SSC     -> Screen Shot Circuit
                  - This command screeshots your circuit!

                CSS     -> Change Speaker Song
                  - This command changes the speaker song on your circuit!

                TPULSE  -> Type Pulse
                  - This command changes the pulsation effect when signal flows through wires!

                CW      -> Clear Workspace
                  - This command clears your workspace!

                RWT     -> Reset Workspace Transform
                  - This command takes you back to the default view if you get lost traversing the Workspace!

                HGAA    -> Hide Grid And Axis
                  - If you don't like the axis and grid showing on the Workspace, you can disable it with this command!

                SGAA    -> Show Grid And Axis
                  - If you want to see the axis and grid again, you can enable it with this command!

                MOP     -> Move All Positions
                  - If you want to move all objects by a certain amount on either the X or Y axis, use this command!



            Appendix 11 -   The "User Manual" Button

                

                This is the button you've obviously clicked to get to this page - or maybe you havent...

                Here, you can view the concisely ordered manual and information about Simboard and Logic Gates!



            Appendix 12 -   The Filter Button

                This button allows you to either EXCLUDE or INCLUDE logic gate objects from the Object Menu. 

                By entering 'EXC', standing for EXCLUDE into the prompt, you will be able to remove a single 
                category of Logic Gate object from the Object Menu!

                By entering 'INC', standing for INCLUDE into the prompt, you will be able to remove every 
                other category of Logic Gate object except for one from the Object Menu!



            Appendix 13 -   Logic Gate Button

                There are various Logic Gate objects available, including:

                The Button

                    

                    The Button, aka. the Hold Button, is one of two inputs available in Simboard. 
                    It acts as a determinant, and sends a binary 1 signal if you click it, or outputs
                    a binary 0 signal if you click it again. 

                    Below, we can see what happens when a button connected to an output object is toggled 
                    ON or OFF:

                    

                    And we can also see what happens when a button is connected to multiple inputs!

                    


                The AND Gate

                    

                    The AND Gate takes in multiple inputs, usually two, and only outputs a binary 1 to 
                    the next gate when all of binary signals coming into it are a binary 1. 

                    We can see this more clearly below:

                    

                    AND Gates also operate with the same rule when many inputs are connected to it!
                    (Although, this isn't industry standard...)

                    


                The OR Gate

                    

                    The OR Gate takes in multiple inputs, usually two, and outputs a binary 1 when 
                    ANY of the binary signals coming into it are a binary 1. 

                    We can see this more clearly below:

                    

                    OR Gates also operate with the same rule when many inputs are connected to it!
                    (Although, this isn't industry standard...)

                    


                The NOT Gate

                    

                    The NOT Gate takes in one input, and inverts the binary signal parsed into it. 
                    For example, if there is a binary 1 signal coming in, the NOT Gate will output 
                    a binary 0. 
                    And if there is a binary 0 signal coming in, the NOT Gate will output a 
                    binary 1. 

                    We can see this more clearly below:

                    

                    NOT Gates also operate with the same rule when many inputs are connected to it! 
                    Essentially, the NOT Gate will take the average of all binary signals coming in, 
                    and make a decision. 
                    So even if one binary signal is 1, and the rest are 0, the NOT Gate will still 
                    output a binary signal of 0. 

                    NOT Gates don't take in multiple inputs as an industry standard, yet we can see 
                    the concept clearly below:

                    

                    NOT Gates can also act as a non-determinant, constant input of a Binary 1 that 
                    cannot be toggled, if it is by itself, plugged into another target gate, as 
                    seen below:

                    

                    This occurs because nothing is entering into the NOT Gate, and it interprets 
                    that as a Binary 0, which is why it outputs a Binary 1. 


                The XOR Gate

                    

                    The XOR Gate takes in multiple inputs, usually two, and outputs a binary one when 
                    an odd number of binary signals coming into it are of a binary signal 1. 

                    So if one signal is a binary 1, and the other is a binary 0, the XOR gate will 
                    output a binary 1, as there are an odd number of Binary inputs.
                    And if both binary signals are either a binary 0 or a binary 1, the XOR gate will 
                    output a binary 0, as there are an even number of Binary inputs.

                    We can see this clearly below: 

                    

                    XOR Gates also operate with the same rule when many inputs are connected to it!
                    (Although, this isn't industry standard...)  

                    


                The Lightbulb

                    

                    The Lightbulb is an output component that, when binary signal flows into it, turns on with a beaming
                    light! This is what an "on" lightbulb looks like:

                    


                The Speaker

                    

                    The Speaker (Audio Speaker) is another output component that, when binary signal flows into it, turns 
                    on playing a song or sound! When the speaker is "on", it should look like this:

                    

                    You can choose the song or sound that the speakers play by clicking the "Talk To System" button, then
                    typing "CSS" into the prompt. Then, you may enter an integer to determine the track of sound you want 
                    to play!
